# Qipa

The AI operating system for modern hospitality.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — product home
- `/platform` — operating system and modules
- `/solutions` — hotels, groups, serviced apartments
- `/contact` — request a briefing

Brand assets live in `public/brand`.
